# Krishna Enterprises — Thermal Power Plant O&M & Commissioning

Official corporate web portal for **Krishna Enterprises**, leading Operation & Maintenance (O&M) service provider for thermal power plants, boilers, steam/gas turbines, FGD systems, and grain distilleries across India.

## Pages
* `index.html` — Homepage
* `about.html` — About Company & Leadership
* `services.html` — Thermal O&M, Overhauling & Services
* `gallery.html` — Project Gallery & Site Operations
* `contact.html` — Contact & Inquiries

## Running Locally
```bash
python main.py
```
Open `http://localhost:8000` in your browser.
